FAQ & Help

Что такое FullMute?

FullMute — это мощный веб-сканер безопасности, предназначенный для автоматизированного сканирования веб-сайтов на наличие уязвимостей, технологий и чувствительных файлов.

Обнаружение технологий

CMS (WordPress, Joomla, Drupal), фреймворки, веб-серверы, базы данных, языки программирования

CVE уязвимости

Автоматическая проверка обнаруженных технологий на известные уязвимости через NVD API

Чувствительные файлы

Поиск .git, .env, конфигов, бэкапов и других потенциально опасных файлов

Планирование

Автоматическое сканирование по расписанию (ежедневно, еженедельно, ежемесячно)

Как использовать

1

Добавьте цели (Targets)

Перейдите на страницу Targets и добавьте домены для сканирования:

  • Вручную через кнопку "Add Target"
  • Массово через "Import TXT" (один домен на строку)
  • Создавайте группы для организации целей
2

Создайте сканирование

Перейдите на страницу Scans и нажмите "New Scan":

  • Выберите цели для сканирования
  • Выберите тип: Manual (один раз) или Scheduled (по расписанию)
  • Запустите сканирование
3

Просмотр результатов

Отслеживайте прогресс на странице Scans:

  • Real-time прогресс сканирования
  • Найденные технологии и CVE
  • Обнаруженные чувствительные файлы
4

Экспорт отчётов

Перейдите на страницу Reports:

  • Выберите группу целей
  • Скачайте JSON отчёт
  • Просмотрите сводную статистику
